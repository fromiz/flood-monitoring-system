# V8.5.17 변경 사항

기준: V8.5.16 전체 코드와 `화면 녹화 중 2026-08-14 175145.mp4`

## 모든 CCTV 창 동시 재생

- 포커스되지 않은 창의 MJPEG를 중단하던 V8.5.16 정책을 제거했습니다.
- 창 포커스는 화면 순서만 바꾸며 다른 CCTV 영상을 멈추지 않습니다.
- 서버가 새 CCTV를 열 때 이전 CameraWorker를 중단하던 코드도 제거했습니다.
- 각 CCTV는 독립 캡처·렌더·박스·단계 워커를 유지합니다.
- 라이브 창이 하나라도 있으면 백그라운드 전체 CCTV 순환 분석은 대기하여 열린 창에 자원을 우선합니다.

## 침수 단계 최소 신뢰도 70%

- `STAGE_MIN_CONFIDENCE=0.70` 설정을 추가했습니다.
- 타이어 또는 차체 단계 모델의 개별 차량 신뢰도가 70% 이상일 때만 단계 투표에 포함합니다.
- 70% 미만 차량은 차량 박스는 계속 표시하지만 침수 단계는 `stage=None`, `stage_valid=false`로 처리합니다.
- 유효 투표가 하나도 없으면 Lev0으로 자동 변경하지 않습니다.
- 유효 투표가 없으면 마지막 승인 단계를 유지하고 DB·지도·목록에 새 단계로 저장하지 않습니다.
- 테스트 CCTV 최소 단계 정책도 70% 이상인 실제 단계 투표가 존재할 때만 적용됩니다.

## 포함 파일

- 전체 소스, 모델, 테스트 영상, 지도 자료
- 실제 `.env` (`STAGE_MIN_CONFIDENCE=0.70` 추가)
- 초기화된 `data/flood_monitor.db`
