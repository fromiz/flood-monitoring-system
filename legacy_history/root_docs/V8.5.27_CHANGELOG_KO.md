# V8.5.27

- GPU stage 지연의 실제 병목 수정: background 분석의 차량 confidence가 0.10으로 강제되던 버그를 제거하고 live detector와 동일한 기준을 사용합니다.
- tire/body 단계 분류 crop 수를 안전하게 제한해 한 CCTV가 GPU를 수십 초 독점하지 않게 했습니다.
- vehicle / tire_level / car_flood_cls 모델 lock을 각각 분리했습니다.
- CCTV 창이 열려 있는 동안 106대 background round-robin AI는 양보하여 live CCTV를 우선합니다.
- CUDA에서 일시적 추론 지연이 있어도 마지막 정상 차량 박스를 2~4초 유지해 박스가 사라지는 현상을 줄였습니다.
- trusted test CCTV는 positive confirmation이 완료되기 전에도 설정된 최소 Lev1 이벤트를 기록할 수 있도록 하단 침수 알람 저장 버그를 수정했습니다.
- KMA APIHub 인증키가 URL-encoded 형태일 때 이중 인코딩되어 HTTP 401이 나던 경우를 수정했습니다. KMA_SERVICE_KEY도 설정되어 있으면 APIHub 실패 시 공공데이터포털 관측값으로 자동 폴백합니다.

> 실제 기상청 연동에는 유효한 `KMA_APIHUB_AUTH_KEY` 또는 `KMA_SERVICE_KEY`가 필요합니다. ZIP에는 사용자 인증키를 포함하지 않습니다.
