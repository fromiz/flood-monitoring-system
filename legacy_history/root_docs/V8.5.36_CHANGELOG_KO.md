# V8.5.36 변경사항

## 박스 표시 경로 고정
V8.5.35는 차량 박스를 서버 JPEG에서 끄고 브라우저 Vector Box에만 의존했습니다. 사용자 실환경에서 영상/WebSocket은 정상인데 박스가 보이지 않는 상태가 재현되어, V8.5.36은 이미 박스 표시가 확인됐던 서버 OpenCV 렌더링 방식으로 복귀합니다.

- 서버 `_draw_live_detections(..., draw_boxes=True)`
- 브라우저 Vector Box 호출 제거
- 따라서 동일 차량 박스가 서버+브라우저에서 이중으로 그려지지 않음
- HLS/버퍼링 관련 코드는 그대로 유지

## 진단 강화
- `CCTV BOX36`: raw / visible / stage-confirmed / top confidence / visible floor / detector ms
- `CCTV WS36`: annotated interest / focus / transport detection metadata / result age
- 조건부 로그가 아니라 AI/transport가 살아 있으면 주기적으로 상태를 확인할 수 있도록 변경
