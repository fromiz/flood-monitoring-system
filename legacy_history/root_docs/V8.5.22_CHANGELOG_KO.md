# V8.5.22 변경 내역

## 1. 영상 렉 감소

### raw snapshot 렌더링 race 완화
V8.5.21의 배경 CCTV는 짧은 `/api/cctv/frame-raw` 요청이 있을 때만 raw JPEG를 생성하는 구조였습니다. 요청이 끝난 직후 다음 요청이 들어오기 전 사이에 raw client 수가 0이 되면 렌더 루프도 raw JPEG 생성을 멈출 수 있어, 여러 창에서 순간적인 대기/지연이 반복될 수 있었습니다.

V8.5.22는 raw 요청 뒤 약 1.8초 동안 `raw interest`를 유지합니다. 따라서 짧은 polling 사이에도 fresh raw JPEG가 계속 준비되며, 최신 프레임이 0.22초 이내라면 바로 반환합니다. 서버 요청 대기시간도 단축했습니다. 또한 배경창 raw JPEG 인코딩은 약 5fps로 제한하여 CCTV 창이 여러 개 열렸을 때 12fps × 창 개수만큼 불필요한 JPEG 인코딩이 발생하지 않도록 했습니다.

### AI 처리 부하 완화
- 차량 rescue 목표: 6대 -> 3대
- rescue confidence: 0.05 -> 0.12
- rescue imgsz: 704 -> 640
- rescue 반복 간격: 약 1.15초 -> 2.5초
- stage classifier는 start-to-start 최소 간격을 두어 geometry detector/영상 렌더링과 계속 경쟁하지 않도록 변경

이 조정은 원거리 차량을 전부 버리는 것이 아니라, 매초 3분할 고해상도 추론이 반복되어 영상 프레임을 밀어내는 현상을 줄이기 위한 것입니다.

## 2. 차량 박스 정상화

### 오검출/중복 박스 필터 강화
차량 detector 결과에서 다음을 제거합니다.

- 너무 작아 유효한 차량으로 보기 어려운 박스
- 지나치게 납작하거나 세로로 긴 비정상 aspect ratio
- 화면 대부분을 차지하는 비정상 박스
- full-frame 검출과 tiled rescue가 같은 차량에 만든 중복 박스

중복 제거는 IoU뿐 아니라 작은 박스 기준 중첩률과 중심/크기 유사도를 함께 사용합니다.

### optical-flow 박스 흔들림 개선
기존 추적은 특징점 퍼짐 정도로 박스 크기까지 매 프레임 다시 계산할 수 있어 도로/차량 경계의 optical flow가 흔들리면 박스가 커지거나 찌그러질 수 있었습니다.

V8.5.22의 기본 추적은:

- 차량 박스 내부 특징점만 사용
- 중앙 이동량의 robust median 기반
- 박스 크기는 유지하고 x/y 이동만 반영
- 비정상적으로 큰 이동량 제한
- flow가 불안정하면 짧게 감속한 뒤 고정

으로 변경했습니다.

또 fresh detector 결과끼리 한 번 더 near-duplicate cleanup을 적용하고, 라벨 위치도 겹치지 않는 후보 위치를 선택합니다.

## 3. 장시간 CCTV 끊김 자동 복구

### 브라우저 MJPEG watchdog
Chrome/Chromium에서 무한 MJPEG `<img>` 연결이 오래 유지된 뒤 더 이상 새 JPEG를 그리지 않는 경우를 대비해:

- 선택 CCTV는 45초마다 raw 화면을 아래에 유지한 채 AI MJPEG 연결만 재생성
- `img.onerror` 시 자동 재연결
- 첫 AI 프레임이 일정 시간 내 표시되지 않으면 자동 재연결
- 4초 주기의 worker 상태 확인에서 서버 프레임 또는 annotated render가 오래됐으면 자동 재연결
- capture/render 핵심 스레드가 예외로 종료된 worker는 `is_alive()`에서 실패 처리하여 다음 요청이 새 worker를 만들도록 변경
- 탭이 숨겨져 있을 때 불필요한 재연결/polling을 줄임

을 추가했습니다.

### HLS 세그먼트 정지 watchdog
HLS media playlist 자체는 정상 응답하지만 최신 segment 번호가 더 이상 증가하지 않는 상황을 감지합니다.

- 약 3.5초 동안 새 segment가 없으면 master/media playlist를 다시 resolve
- 약 8초 이상 진행이 없으면 HLS 경로를 버리고 전체 연결을 다시 시도
- stall reset 횟수를 worker 상태에 기록

이전처럼 마지막 segment를 계속 기다리면서 영구 정지하는 상태에 머물지 않습니다.

## 4. 프런트 렌더링 분리

`.cctv-body`에 paint containment를 적용하고 선택 CCTV 영상에 compositor 힌트를 적용하여, 영상 `<img>`가 자주 갱신될 때 아래 침수 기록/차트 영역까지 매 프레임 크게 다시 그리는 비용을 줄였습니다.
