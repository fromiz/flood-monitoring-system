# V8.5.33 변경사항

- V8.5.32 FULL에서 서버가 그린 박스와 브라우저 vector 박스를 동시에 표시하던 이중 렌더 제거
- 진단용 0.001 confidence를 production 0.03으로 복구하고 4% 미만 후보 미표시
- 4~12% 원거리 후보는 2~3회 연속 위치 확인 후 표시, 12% 이상 full-frame 후보는 즉시 표시
- full/tile/CLAHE 중복 박스를 IoU + 포함률 + 중심거리로 강하게 병합
- GPU에서는 missed track carry를 제거해 지나간 차량의 낡은 박스가 남지 않게 함
- GPU fresh detection에 optical-flow 재투영을 적용하지 않아 도로선/반사에 박스가 끌려가는 현상 방지
- 침수단계 tire/body 분석은 한 주기 최대 4대만 처리해 영상/차량탐지 GPU 우선권 확보
- HLS가 뒤처졌을 때 중간 세그먼트를 모두 재생하지 않고 최신 live segment로 점프
- WebSocket 총 전송량을 낮춰 여러 CCTV 동시 표시 시 브라우저 JPEG decode 부담 완화
- best -> crop -> tire_level -> 타이어 미검출 시 car_flood_cls 순서는 유지
