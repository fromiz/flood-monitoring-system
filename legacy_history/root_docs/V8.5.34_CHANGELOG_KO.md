# V8.5.34 변경사항

## 이번 버전의 목적
V8.5.33에서 영상 버퍼링은 개선됐지만 실제 포항 야간 CCTV에서 `vehicles 0`이 유지되는 문제를 수정합니다.

## 원인
- V8.5.32 진단판은 `best.pt` raw confidence 0.001까지 받아 차량 박스가 보였습니다.
- V8.5.33은 오탐을 줄이려고 모델 입력 confidence를 0.03으로 올리고 후단에서 0.04 미만을 제거했습니다.
- 포항 야간 CCTV의 실제 차량 중 일부는 raw detector confidence가 이보다 낮아 Ultralytics 단계에서 박스 자체가 사라질 수 있었습니다.
- 동시에 V8.5.33 브라우저는 annotated JPEG일 때 vector bbox를 그리지 않았기 때문에, 서버 렌더 박스가 비면 metadata에 bbox가 있어도 화면에 나타나지 않았습니다.

## 수정
1. GPU `best.pt` raw confidence를 다시 0.001로 열었습니다.
2. 낮은 confidence 후보는 즉시 표시하지 않고 2~5회의 공간적 반복 확인으로 승격합니다.
3. 강한 class-agnostic de-duplication은 유지합니다.
4. GPU는 missed box carry=0, bbox alpha=1.0을 유지해 예전 박스를 끌고 가지 않습니다.
5. 실시간 JPEG에는 차량 박스를 굽지 않습니다. privacy/status만 인코딩합니다.
6. 차량 bbox는 WebSocket metadata를 이용해 브라우저에서 정확히 한 번만 그립니다.
7. 따라서 annotated/raw 전환에도 박스가 사라지지 않고, 서버 박스 + vector 박스 중복도 생기지 않습니다.
8. V8.5.33에서 해결된 HLS/버퍼링 경로는 변경하지 않았습니다.

## 침수단계 파이프라인
`best.pt -> vehicle crop -> tire_level.pt -> (타이어 미검출 시) car_flood_cls.pt`

`tire_level.pt`를 제거하거나 우회하지 않습니다.
