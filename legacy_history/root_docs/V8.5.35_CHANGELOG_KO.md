# V8.5.36 변경 사항

- V8.5.34의 핵심 버그 수정: temporal confirmation을 차량 **박스 표시의 하드 게이트**로 사용하지 않습니다.
- GPU에서는 `best.pt`의 현재 프레임 raw bbox를 강한 class-agnostic 중복 제거 후 즉시 표시합니다.
- raw confidence의 near-zero 꼬리를 제거하기 위해 `max(0.003, top_conf*0.12)` 기반 동적 표시 바닥값을 사용하고 최대 12개만 표시합니다.
- 약한 박스는 CHECK 상태로 보이지만, 2~5회 시간축 확인 전에는 `tire_level.pt`/`car_flood_cls.pt`로 보내지 않습니다.
- 따라서 **박스 가시성**과 **침수단계 판정 신뢰성**을 분리했습니다.
- GPU에서는 이전 박스 carry=0, bbox blending 없음, optical-flow 재투영 없음 정책을 유지합니다.
- V8.5.34에서 `logger.info()`라 실제 PowerShell에 나오지 않던 `raw/confirmed` 진단 로그를 `WARNING`으로 수정했습니다.
- worker-status에 `raw_detection_count`, `visible_detection_count`, `stage_confirmed_count`, `visible_confidence_floor`를 추가했습니다.
- V8.5.34에서 해결된 HLS/버퍼링 경로는 변경하지 않았습니다.
