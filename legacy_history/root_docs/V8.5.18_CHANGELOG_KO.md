# V8.5.18 변경 사항

기준: V8.5.17 전체 코드와 `화면 녹화 중 2026-08-14 214756.mp4`

## 이번 녹화에서 확인한 실제 원인

1. 백그라운드 CCTV의 단일 고신뢰 오분류 한 건이 즉시 DB·지도·전체 최대값에 반영되어 `Lev4 / 70cm`가 표시됐습니다.
2. 열린 모든 창이 `/api/stream-annotated`를 사용해 창마다 캡처, 차량 검출, 단계 분류, 개인정보 분석, 광학 추적을 동시에 시작했습니다.
3. 포커스되지 않은 창도 96장의 960px 추적 이력을 유지해 창 수에 따라 CPU·메모리 사용량이 증가했습니다.
4. V8.5.16의 원거리 타일 검출이 차량 3대 미만인 장면에서 매 주기 실행되어 최신 박스 갱신을 지연시켰습니다.
5. 검출이 늦는 동안 광학 흐름을 최대 12초 가까이 유지해 박스가 차량 대신 도로·조명 특징을 따라갔습니다.

## 1. 정상 지역 침수 오탐 차단

- 70% 미만 개별 차량 단계는 기존과 같이 투표에서 제외합니다.
- 공개 CCTV의 양성 단계는 최소 2대 차량, 양성 비율 75% 이상이어야 후보가 됩니다.
- 같은 양성 단계가 5회 연속, 최소 3초 동안 확인돼야만 승인합니다.
- 확인 전에는 DB, 지도, 목록, 최대 침수등급에 반영하지 않습니다.
- 과거 버전에서 저장된 `positive_confirmed=true` 없는 양성 DB 행도 지도에서 제외합니다.
- Lev0은 즉시 반영하며 번들 침수 테스트 영상만 신뢰 테스트 정책을 유지합니다.
- 백그라운드에서 양성 후보가 나오면 동일 순환에서 추가 프레임을 확인합니다.

## 2. 여러 CCTV 창 영상 동시 표시

- 모든 비포커스 창은 가벼운 `/api/stream-raw` 영상을 계속 표시합니다.
- 포커스 창 하나만 `/api/stream-annotated`로 차량·침수 AI를 실행합니다.
- 원본과 분석 스트림은 같은 CameraWorker와 같은 HLS/OpenCV 연결을 공유합니다.
- 포커스를 바꿔도 상류 CCTV 연결은 끊거나 다시 열지 않습니다.
- 비포커스 창은 AI·광학추적·개인정보 분석·추적 이력을 생성하지 않습니다.

## 3. 차량 박스 추적

- 포커스 분석 프레임을 640px에서 960px로 복원했습니다.
- 차량 박스 검출은 시작-시작 기준 0.4초 간격으로 실행합니다.
- 타일 보강 검출은 박스가 완전히 없을 때만, 최대 2.5초에 한 번 실행합니다.
- 광학 흐름은 최신 검출 후 최대 0.65초만 사용합니다.
- 0.65초를 넘으면 잘못된 박스를 끌고 가지 않고 새 검출까지 숨깁니다.
