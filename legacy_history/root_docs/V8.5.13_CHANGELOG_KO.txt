포항 침수 통합관제 V8.5.13 변경 사항

1. CCTV 재생 및 추적
- 네트워크 CCTV 연결 제한 시간을 줄이고 연결 중 안내 프레임을 즉시 표시합니다.
- HLS 확인이 오래 걸릴 때 무한 대기하지 않고 빠르게 복구합니다.
- 영상별 분석 결과 순서를 보존해 이전 프레임의 박스가 새 프레임을 덮지 않도록 했습니다.
- 로컬 테스트 CCTV는 실제 분석 결과를 우선하며, 분석 전에는 설정된 기준 단계만 사용합니다.
- 단계별 차량 수가 같으면 평균 신뢰도가 높은 단계를 선택합니다.

2. 침수 그래프
- CCTV 창을 열면 현재 단계를 먼저 그려 빈 그래프 대기 시간을 줄였습니다.
- 이전 요청을 취소하고 최신 요청만 반영해 늦게 도착한 응답이 그래프를 되돌리지 않게 했습니다.
- CCTV 좌표를 함께 보내 목록 API 재조회 없이 저장 이력을 조회합니다.

3. 침수심 지도
- CCTV 위치와 확인 단계, 주변 고도, 지형 경사, 하천·바다, 도로 연결성,
  최대 영향 반경, 실제 침수 가능도, 과거 침수 이력을 함께 반영합니다.
- 15m 격자의 DEM을 묶어서 읽고 도로·수계 문맥을 병렬로 불러옵니다.
- 낮은 지형과 골짜기, 도로 연결부, 하천 인접부를 우선하고 고지대 확산을 억제합니다.
- 지도 계산 중에는 CCTV 위치에 임시 표시를 내보내고 자동으로 다시 요청합니다.
- 테스트 CCTV의 단계는 지점을 클릭하기 전에도 통합 지도 요청에 반영됩니다.
- 침수 자료가 없거나 계산에 실패하면 이전 침수 면을 남기지 않는 fail-closed 방식입니다.

4. 날씨 및 저장 조회
- 기존 기상 API 설정 방식을 유지하며 CCTV/환경 이력 조회 인덱스를 추가했습니다.
- .env 파일과 API 키는 배포 ZIP에 포함하지 않습니다.

주의
- 실제 도로·수계·DEM 자료를 사용하려면 .env에 VWORLD_API_KEY와 관련 URL 설정이 필요합니다.
- 외부 데이터 API가 차단되거나 키 사용 범위를 벗어나면 임시 CCTV 위치 표시 후 재시도합니다.
- 이 지도는 CCTV와 지형 자료를 결합한 추정 결과이며 법정 침수도나 수리·수문 해석을 대체하지 않습니다.
