포항 도시침수 통합관제 V8.4.0 변경사항

1. CCTV 동시 열기 제한 해제
- 기존 최대 4개 제한 제거
- 열린 CCTV 수만 표시
- 실제 동시 처리 가능 수는 PC CPU, 메모리, 네트워크 성능에 따라 달라짐

2. CCTV 자동 정렬
- 메인 지도 도구의 'CCTV 자동 정렬' 버튼 추가
- 열린 창을 지도 영역에 격자 정렬
- 창이 많거나 셀이 작으면 이력 그래프를 자동 숨김
- 제목줄을 끌면 개별 이동 모드로 복귀

3. 하수도/하천 수위계 탭
- 기존 하수도 수위계 패널에 탭 UI 추가
- /api/sewer-levels
- /api/river-levels
- JSON/XML, items/item/sensors/data/records 구조 자동 파싱
- wlobscd, wlobsnm, wal, flux, obsrdate 필드 인식

4. 테스트 CCTV 위치 변경
- 애니시 인근
- 주소: 경상북도 포항시 북구 학전로 142 (장성동 1259-1)
- 좌표: 36.06418, 129.37762
- 주소 인근 좌표이므로 실제 설치 시 현장 좌표로 보정 필요

5. 고도 확인
- 메인 지도에 '고도 확인 OFF/ON' 버튼 추가
- 브이월드 실제 3D와 침수 분석지도에서 클릭 지점 DEM 고도 표시
- /api/dem/elevation 추가

6. 보안
- 배포 ZIP의 .env 및 .env.example 인증키 값은 비워 둠
- 기존 운영 폴더의 인증키를 새 .env에 직접 다시 입력해야 함
