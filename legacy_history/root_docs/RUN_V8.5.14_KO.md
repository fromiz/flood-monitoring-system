# V8.5.14 실행

1. 압축을 새 폴더에 풉니다.
2. 기존 프로젝트의 `.env`만 V8.5.14 최상위 폴더로 복사합니다.
3. 기존 실행 방법 또는 `start.bat`을 사용합니다.
4. 브라우저에서 `Ctrl+F5`를 한 번 눌러 V8.5.14 JavaScript와 CSS를 새로 받습니다.

## 첫 확인 순서

1. 서버를 실행하고 CCTV를 클릭하기 전에 10초 정도 기다립니다.
2. 테스트 CCTV가 최소 Lev1 색상으로 표시되는지 확인합니다.
3. 테스트 CCTV를 열면 침수 단계 그래프가 서버 응답 전 즉시 수평선으로 표시되는지 확인합니다.
4. 창을 닫고 잠시 기다린 뒤 다시 열어 이전 시간이 그래프와 표에 남는지 확인합니다.
5. 1분 이상 열어 두어도 테스트 CCTV가 녹색 Lev0으로 돌아가지 않는지 확인합니다.
6. 빠르게 이동하는 차량에서 느린 단계 판정이 도착할 때 박스가 과거 위치로 튀지 않는지 확인합니다.

배포 ZIP에는 `.env`, API 키, 데이터베이스와 실행 캐시가 들어 있지 않습니다.
