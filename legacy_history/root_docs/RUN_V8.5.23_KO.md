# V8.5.23 실행 방법

## 기존 버전에서 교체

1. 실행 중인 V8.5.22 서버의 명령창을 완전히 종료합니다.
2. `flood-monitor-v8.5.23` 폴더를 **새 폴더에 별도로 압축 해제**합니다. 기존 폴더 위에 덮어쓰는 방식은 권장하지 않습니다.
3. 기존에 사용하던 `.env`를 직접 복사하기보다 이번 ZIP의 `.env`를 기본으로 사용한 뒤 API 키/DB 주소처럼 사용자가 별도로 입력한 값만 옮기는 것을 권장합니다. V8.5.23에는 CCTV 성능 관련 기본값이 변경되어 있습니다.
4. Windows에서는 `START_V8.5.23.bat`를 실행합니다.
5. 브라우저를 연 뒤 처음 한 번 `Ctrl+F5`를 눌러 V8.5.23 JavaScript/CSS를 새로 받습니다.

## 최초 설치인 경우

압축을 푼 V8.5.23 폴더에서 Python 가상환경을 만들고 requirements를 설치합니다.

```bat
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

설치 후:

```bat
START_V8.5.23.bat
```

브라우저에서 기본적으로 아래 주소를 엽니다.

```text
http://127.0.0.1:8000
```

## CCTV 확인 순서

- CCTV 창을 1개 열고 첫 화면과 박스가 표시되는지 확인합니다.
- 3~6개 정도를 열어 자동 정렬한 뒤 **모든 창에 박스가 표시되는지** 확인합니다.
- 마지막으로 선택한 창은 AI 갱신 우선순위가 높아지고, 다른 창도 박스를 계속 유지합니다.
- 최소 10~20분 이상 켜 두고 화면이 사라지지 않는지 확인합니다.

문제가 남는 특정 CCTV가 있으면 CCTV 이름과 발생 시점이 보이는 화면 녹화를 보내 주면 해당 스트림의 패턴을 기준으로 추가 조정할 수 있습니다.
