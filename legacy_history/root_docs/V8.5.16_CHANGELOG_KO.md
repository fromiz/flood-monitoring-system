# V8.5.16 변경 사항

기준 소스: V8.5.15 전체 코드와 `화면 녹화 중 2026-08-14 173310.mp4`

## 녹화에서 확인한 현상

- CCTV 창이 여러 개 겹쳐 열린 상태에서 이전 창도 MJPEG 연결과 AI 워커를 계속 유지했습니다.
- 선택된 `창포사거리`에서는 차량 7대의 박스가 표시되어 모델 파일 자체는 정상임을 확인했습니다.
- 일부 이전 CCTV는 검은 화면/연결 대기 상태인데도 재접속 작업을 계속 수행했습니다.

## 실제 원인

1. 여러 CCTV 창의 스트림·재접속·AI 작업이 동시에 실행되어 새 CCTV가 자원을 제때 받지 못했습니다.
2. 박스 스레드와 단계 스레드는 분리됐지만 세 모델의 추론 잠금이 하나여서, 느린 타이어/차체 분류 중 `best.pt` 차량 검출도 정지했습니다.
3. 실시간 박스 검출은 416px 전체 화면만 사용해 넓은 CCTV 화면의 작고 먼 차량을 놓쳤습니다.

## 수정

- 포커스된 CCTV 하나만 실시간 스트림과 AI를 실행합니다.
- 이전 CCTV 창은 그래프·검색 결과를 유지한 채 영상만 일시정지합니다.
- 서버에서도 새 CCTV가 열리면 이전 캡처·추론 워커를 즉시 중지합니다.
- 차량·타이어·차체 모델에 각각 독립 추론 잠금을 적용했습니다.
- 전체 화면에서 차량이 3대 미만이면 3개 중첩 타일로 원거리 차량을 즉시 재검출합니다.
- 전체 화면/타일 중복 박스는 IoU 0.55 기준으로 제거합니다.
- 타일 검출 시간이 길어져도 추적 이력 범위 안이면 결과를 폐기하지 않고 현재 프레임으로 투영합니다.
