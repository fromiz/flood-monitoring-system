# V8.5.22 실행 방법

이 ZIP은 V8.5.21을 기반으로 **영상 렉**, **차량 박스 중복/흔들림**, **장시간 실행 뒤 CCTV 정지**를 개선한 전체 파일입니다. `.env`, 초기화 DB, 테스트 CCTV 영상이 포함되어 있습니다.

## 처음 한 번 설치 (Windows PowerShell)

압축을 푼 **V8.5.22 폴더 안에서** 아래 명령을 실행합니다.

```powershell
py -m venv .venv
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

설치 후 `START_V8.5.22.bat`를 더블클릭합니다.

접속 주소: `http://127.0.0.1:8000`

## V8.5.21에서 교체할 때

1. 실행 중인 V8.5.21 서버 창을 완전히 종료합니다.
2. V8.5.22 ZIP을 **새 폴더**에 압축 해제합니다.
3. 기존 `.venv`를 새 폴더로 복사하지 않았다면 위의 최초 설치를 진행합니다.
4. `START_V8.5.22.bat`로 실행합니다.
5. 브라우저에서 `Ctrl+F5`를 한 번 눌러 V8.5.22 JavaScript/CSS를 새로 받습니다.
6. 실제 CCTV를 여러 개 열어 5분 이상 유지하고, 선택 CCTV를 바꿔가며 영상/박스 상태를 확인합니다.

## 이번 버전의 핵심 동작

- 선택된 CCTV의 AI MJPEG는 45초마다 화면 뒤의 raw 프레임을 유지한 채 연결만 안전하게 갱신합니다. Chromium의 장시간 MJPEG 정지를 자동 복구하기 위한 동작입니다.
- 서버의 실제 프레임 갱신이 멈춘 경우에도 4초 상태 점검에서 감지해 AI 스트림을 다시 연결합니다.
- HLS 재생목록이 같은 세그먼트에 멈추면 media playlist를 다시 확인하고, 오래 멈추면 전체 CCTV 연결을 재시도합니다.
- 배경 CCTV는 짧은 raw JPEG 요청을 사용하되, 서버가 raw 프레임을 잠깐 유지하는 lease를 둬 요청 사이에 렌더러가 꺼졌다 켜지는 현상을 줄였습니다.
- 차량 박스 detector는 너무 낮은 confidence와 과도한 3분할 rescue를 완화하고, 비정상 크기/비율 박스 및 중복 박스를 제거합니다.
- optical flow 추적은 박스 크기를 매 프레임 확대/축소하지 않고 **이동량만** 따라가도록 하여 박스가 갑자기 커지거나 다른 차량으로 튀는 현상을 줄였습니다.
- 차량 라벨이 겹칠 때 위/아래 빈 공간을 찾아 배치합니다.

## 참고

실제 포항 CCTV 원본 서버 자체가 송출을 중단했거나 외부망에서 접근할 수 없는 카메라는 프로그램에서 영상을 생성할 수 없습니다. V8.5.22는 원본 송출이 살아 있는 상황에서 브라우저 연결/HLS 세그먼트/AI 처리 지연 때문에 멈추는 경우를 자동 복구하도록 개선한 버전입니다.
